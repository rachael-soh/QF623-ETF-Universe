# Data Directory

This folder holds all raw and processed data for the ETF long/short project.
**No data files are committed to the repository** — all parquet and CSV files are git-ignored.
This document explains every file and how to regenerate it.

---

## Folder Structure

```
data/
├── external/          ← Universe definition (provided, not auto-generated)
│   ├── etf_universe.csv          (old universe — superseded)
│   └── etf_universe.txt
│
├── raw/               ← Pulled directly from WRDS — regenerate with notebooks below
│   ├── crsp_etf_names.parquet        (original name pull — smaller universe)
│   ├── crsp_etf_names_full.parquet   (broader name pull — all tickers + CUSIPs)
│   ├── crsp_etf_daily.parquet        (original daily pull — smaller universe)
│   └── crsp_etf_daily_new.parquet    (full daily pull — all 1,630 permnos, 2011–present)
│
└── processed/         ← Outputs of the cleaning pipeline — regenerate by running the notebook
    ├── etf_universe_clean.parquet    (deduplicated universe + computed stats)
    ├── etf_bonds.parquet             (nominal bond ETF subset)
    ├── etf_treasury.parquet          (Treasury ETF subset)
    ├── etf_sector.parquet            (sector equity ETF subset)
    ├── returns_treasury.parquet      (wide return panel: dates × Treasury tickers)
    ├── returns_sector.parquet        (wide return panel: dates × Sector tickers)
    └── returns_all.parquet           (wide return panel: dates × all ETFs)
```

## Data Sources

### 1. ETF Master Universe (`external/`)

**Source:** ETF Global (ETFG) database, accessed via the course.

**File:** `clean_etf_master_universe.csv` (located at the project root — not committed)

**Coverage:** 1,630 ETFs pre-screened for quality (no leveraged, no inverse, no ETNs). Contains metadata including:
- AUM, expense ratios, primary benchmark, category, focus
- Liquidity metrics: average/median daily dollar volume, bid-ask spread
- Data quality flags: stale price, extreme return, zero-volume flags

**Not redistributed** — obtain from course materials.

---

### 2. CRSP Name History (`raw/crsp_etf_names_full.parquet`)

**Source:** `crsp.dsenames` on WRDS

**How to regenerate:** Run the **"ONE-TIME WRDS PULL — names"** cell in
`PM_GroupProject_Trial1_DataCleaning_7thJun26.ipynb`.

**Query logic:**
```sql
SELECT permno, cusip, ticker, namedt, nameendt, shrcd, exchcd, comnam
FROM crsp.dsenames
WHERE cusip IN (...all universe CUSIPs...)
   OR ticker IN (...all universe tickers...)
```

No share-code filter is applied, so the pull captures ETFs coded under any CRSP share class (not just `shrcd = 73`).

---

### 3. CRSP Daily Returns (`raw/crsp_etf_daily_new.parquet`)

**Source:** `crsp.dsf` on WRDS

**Coverage:** January 2011 → present (updated to `CURRENT_DATE` each time the pull runs)

**Fields:** `permno`, `date`, `ret`, `prc`, `vol`, `shrout`

**How to regenerate:** Run the **"ONE-TIME WRDS PULL — daily returns"** cell in
`PM_GroupProject_Trial1_DataCleaning_7thJun26.ipynb`.

**Query logic:**
```sql
SELECT permno, date, ret, prc, vol, shrout
FROM crsp.dsf
WHERE permno IN (...all 1,630 universe permnos...)
  AND date BETWEEN '2011-01-01' AND CURRENT_DATE
```

> **Expected size:** ~5–8 million rows, ~200–400 MB on disk as Parquet.

### 4. Processed Outputs (`processed/`)

Generated by running `PM_GroupProject_Trial1_DataCleaning_7thJun26.ipynb` end-to-end after the raw pulls are complete.

| File | Shape | Description |
|------|-------|-------------|
| `etf_universe_clean.parquet` | ~N × 92 | Full deduplicated universe with all metadata and computed stats (ann_return, ann_vol, daily_vol) |
| `etf_bonds.parquet` | ~N × 92 | Nominal bond ETF subset (Treasury + Corporate + HY + Aggregate) |
| `etf_treasury.parquet` | ~N × 92 | Treasury-only ETF subset |
| `etf_sector.parquet` | ~N × 92 | Sector equity ETF subset (one ETF per GICS sector) |
| `returns_treasury.parquet` | dates × tickers | Wide daily net-of-fee return panel — Treasury ETFs |
| `returns_sector.parquet` | dates × tickers | Wide daily net-of-fee return panel — Sector ETFs |
| `returns_all.parquet` | dates × tickers | Wide daily net-of-fee return panel — full universe |

## Replication Steps (from scratch)

1. Obtain `clean_etf_master_universe.csv` from course materials and place it at the project root.
2. Ensure WRDS credentials are configured (`~/.pgpass`).
3. Open `PM_GroupProject_Trial1_DataCleaning_7thJun26.ipynb`.
4. Run the **WRDS names pull** cell (Step 3 in the notebook) — saves `crsp_etf_names_full.parquet`.
5. Run all cells through the **cascade match** cell — resolves permno for all ETFs.
6. Run the **WRDS daily pull** cell (Step 4 in the notebook) — saves `crsp_etf_daily_new.parquet`. *This may take several minutes.*
7. Run all remaining cells — saves processed outputs to `data/processed/`.

## Notes on Data Quality

- **`ret` missing codes:** CRSP encodes missing returns as the string `'C'`. The pipeline converts these to `NaN` with `pd.to_numeric(..., errors='coerce')`.
- **Survivorship bias:** Delisted ETFs are retained in the panel. Their return series naturally truncates at the last trading date.
- **Expense ratio drag:** Net-of-fee returns are computed as `ret − (net_expenses / 252)` per trading day.
- **CUSIP format:** CUSIPs in the universe file may be stored as floats (9-digit number without the check-digit period). The pipeline normalises these to 8-character strings to match CRSP's format.
